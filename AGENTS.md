# Правила разработки Markdown Reader

- Соблюдайте стандарт C++20. Для интерфейса используйте Qt 6 Widgets.
- Обрабатывайте Markdown через QTextDocument и отображайте его через QTextBrowser. Не используйте Qt WebEngine.
- Сохраняйте кроссплатформенность для Windows, macOS и Linux. Держите платформозависимый код за пределами основной логики.
- Минимизируйте зависимости и сохраняйте простую архитектуру. Переиспользуйте возможности Qt.
- Покрывайте новую логику тестами Qt Test. После изменений проверяйте сборку и запускайте CTest. Указывайте, на каких платформах выполнена проверка.
- Не удаляйте и не перезаписывайте пользовательские изменения без необходимости.
