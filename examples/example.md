# Markdown Reader

Локальный документ **Markdown** с *форматированием*. Выберите раздел в левой панели, чтобы перейти к нему.

![Карточка Markdown Reader](reader.png)

## Форматирование

- Маркированный список
- Второй пункт

1. Откройте файл через меню «Файл».
2. Выберите заголовок в дереве.

> Этот пример можно читать без подключения к интернету.

```cpp
const auto title = QStringLiteral("Пример");
```

| Элемент | Назначение |
| --- | --- |
| Дерево | Переход к разделу |
| Разделитель | Изменение ширины панели |
