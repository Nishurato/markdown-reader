# Производительность Markdown Reader 0.2.3

## Воспроизводимый замер

Сначала настройте Release и путь к Qt по [инструкциям сборки](../README.md#сборка-и-запуск). Следующие команды из корня проекта используют параметры уже настроенного `build/release`.

```sh
cmake --preset release -DMARKDOWN_READER_BUILD_BENCHMARK=ON
cmake --build --preset release --target markdown_reader_benchmark
python tools/benchmark.py generate build/benchmark-fixtures
python tools/benchmark.py run build/release/markdown_reader_benchmark build/benchmark-fixtures/mixed.md
python tools/benchmark.py run build/release/markdown_reader_benchmark build/benchmark-fixtures/with-images.md
```

В Windows добавьте `.exe` к имени измерительного файла и оставьте Qt 6.8.3 в `PATH`. На Linux и macOS используйте `python3`, если команда `python` отсутствует. Запускайте в обычном графическом сеансе. Для автоматического прогона Linux допустим `xvfb-run -a env QT_QPA_PLATFORM=xcb` перед командой Python. Зафиксируйте, какой графический сеанс использовался.

Генератор создаёт два файла ровно по **1 048 576 байт**. В обоих есть заголовки, абзацы, списки, таблицы и блоки кода. `with-images.md` также ссылается на четыре локальных BMP общим объёмом **1 179 864 байта**. Повторная генерация даёт одинаковые байты. Изображения хранятся отдельно от Markdown.

По умолчанию инструмент запускает один прогревочный и пять измерительных процессов для каждого файла. Он выводит все образцы и медианы. Для холодного запуска перезагрузите систему, дождитесь готовности рабочего стола, затем выполните команду с `--warmups 0 --runs 1` до первого открытия приложения или тестового файла. Повторите после как минимум трёх независимых перезагрузок и возьмите медиану `launch_to_paint_ms`. Зафиксируйте ОС, архитектуру, CPU, RAM, масштабирование и конфигурацию виртуальной машины. Снимок VMware с уже прогретым кешем не заменяет перезагрузку.

- `launch_to_paint_ms` отсчитывается от запуска процесса из Python до первого наблюдаемого Qt-кадра стартовой страницы и включает загрузку библиотек. `startup_ms` отсчитывается от входа в `main()` монотонным таймером.
- `open_to_paint_ms` отсчитывается от вызова открытия файла до завершения первого наблюдаемого Qt-кадра области чтения. Это полное отображение с чтением, разбором и компоновкой. Отдельное время чтения с диска здесь не измеряется. Ожидание показа кадра системным композитором также не измеряется.
- Рабочий набор Windows или RSS Linux/macOS снимается через 250 мс работы цикла событий после кадра. Замеры сделаны на пустой странице, после открытия одного документа, после открытия пяти копий в отдельных вкладках и после закрытия этих вкладок. Значение после закрытия включает кеши Qt и распределителя памяти.

## Результаты

Замеры ниже автоматические. В каждой строке приведена медиана пяти процессов после одного прогревочного. Оба локальных прогона выполнены на Intel Core i5-8400. Windows 11 24H2 x64 с 16 ГиБ RAM использовала нативное окно Qt и MSVC 19.51. Ubuntu 22.04.5 x86_64 в WSL2 использовала GCC 11.4, около 7,7 ГиБ доступной памяти и XCB под Xvfb. В обоих случаях использована Qt 6.8.3. Для VMware фиксируйте ресурсы гостевой системы и сравнивайте версии приложения в одинаковой конфигурации.
